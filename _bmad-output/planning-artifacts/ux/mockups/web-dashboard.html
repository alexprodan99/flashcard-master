Why does Raft enforce a strict single-leader model for log replication?
It forces all log entries to flow in a unidirectional stream from the leader to followers, completely eliminating split-brain branching conflicts.
Verbatim Source Quote
"Raft uses a stronger form of leadership... Log entries only flow from the leader to other servers, simplifying state-machine safety."

What is the primary trade-off of using PostgreSQL BRIN indexes over standard B-Tree indexes?
BRIN indexes take up vastly less disk space and memory (~99% smaller) but are only efficient when table data is physically sorted on disk.
Verbatim Source Quote
"BRIN is designed to handle very large tables in which certain columns have a natural correlation with their physical location on disk."

How do Saga patterns manage distributed transactions without two-phase locking?
By executing a series of local transactions across individual microservices, each accompanied by an explicit compensating transaction if a subsequent step fails.
Verbatim Source Quote
"A saga is a sequence of local transactions where each updates data within a single service and publishes an event or message to trigger the next step."
