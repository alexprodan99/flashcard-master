Eliminate: Syntax-Repair Retry Hops

No more sending "Your JSON was malformed, please fix it" repair requests. Retries are strictly reserved for genuine semantic or business rule validations.

- await retryFixingJsonSyntax(rawResponse, parseError);
Purged 100%

Eliminate: Manual Parsing Heuristics

Remove ad-hoc brackets detection, substring slicing, and loose JSON parsers that mask prompt degradation and cause unpredictable runtime failures.

Stream Inversion

Structured Object Streaming

Reverse the monolithic array paradigm: Parse and yield individual cards progressively as objects stream over the wire, preventing batch truncation failures.

for await (const card of streamCards(schema)) { emitSSE(card); }
Partial Retention

Partial Output Retention

Monolithic array generation is vulnerable to output token limits. Streaming items preserves valid cards generated prior to token limits, accompanied by friendly UI warning banners.

saveValidCards(partialList); notifyUser("Retained 7 cards before limit");
Execution Inversion

Grammar-Guided Decoding

Instead of generating unconstrained text and validating downstream, inverse the control: provider grammar engines mask illegal tokens at generation time.

Token Masking: Valid tokens only allowed by JSON state machine

// ❌ Fragile string regex heuristics & fence hacking
async function parseFlashcards(raw: string) {
  // Strip markdown backticks & thinking tags
  let clean = raw.replace(/```json/gi, "")
                 .replace(/```/g, "")
                 .replace(/<think>[\s\S]*?<\/think>/gi, "")
                 .trim();

  // Attempt regex extraction of array
  const match = clean.match(/\[\s*\{.*\}\s*\]/s);
  if (!match) {
    // 💥 Crash: "Failed to parse generated flashcards JSON:
    //            No valid flashcards found in model output"
    throw new Error("No valid flashcards found");
  }

  // Try/catch repair retry loops
  try {
    return JSON.parse(match[0]);
  } catch (err) {
    return await retryFixingJsonSyntax(clean);
  }
}
