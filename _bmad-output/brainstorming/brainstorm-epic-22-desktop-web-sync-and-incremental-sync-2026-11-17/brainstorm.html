03. Failure Analysis: Trap Matrix

Three subtle failure modes caught before implementation — two structural traps by Coach, one UX trap by User.

Risk Guardrails
[DIAGNOSTIC BOARD] SILENT RE-INGESTION, PATH DRIFT & COUNTER-INTUITIVE DEDUP TRAPS STATUS: MITIGATED IN DESIGN

Sliced Subdocument URL Suffixes

Coach Idea

Timestamp and page fragment suffixes like #t= or #page= mask the underlying parent document or video identity, tricking incremental sync into thinking an already-ingested item is new.

Guardrail Match canonical parent identity (path / URL / GUID / YouTube videoId) before fetching or transcribing.

Worker Thread MediaService Path Drift

Coach Idea

Background worker threads running MediaService can resolve relative or default Electron/OS data directories differently from the main process, splitting media/ and caches.

Guardrail Lock Desktop, Web, CLI, and worker threads onto the single canonical ~/.flashcard-master/ root (with CLI --data-dir only).

Counter-Intuitive PDF Content Dedup

User Idea

Hashing PDF contents across different paths to deduplicate feels counter-intuitive and removes user agency over what Sync New Only includes — whereas YouTube videos have real metadata identity.

Guardrail Match PDFs & local files strictly by file name/path (no cross-path content hash dedup). For YouTube, resolve metadata & deduplicate by videoId.

05. Epic 22 Climax — v1.3.0 Blueprint

All three tracks converged into a single cohesive release train.

PILLAR 01 · UNIFIED STORAGE
