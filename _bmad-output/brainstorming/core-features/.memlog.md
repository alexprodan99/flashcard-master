- (idea by coach) Unified Ingestion Protocol: Resolver automatically detects whether an input is an RSS feed, web URL (reader-mode extract), or local file/glob
- (idea by coach) Incremental Delta Sync Tracker: Remembers processed RSS items and file checksums to only generate Q&A for new/modified content
- (decision by user) Database-backed configuration with extensible DataSourceType and per-type Ingestion Strategy pattern

- (idea by user) Configurable difficulty and customizable agent generation personas (e.g., Socratic tutor, strict examiner)
- (decision by user) Strict source grounding: every card must cite exact source quote/sentence it was derived from
- (idea by coach) Atomic Flashcard Prompt Guard: Enforces single-concept questions (no compound questions, no trivia giveaways, focuses on why/how mechanisms)
- (idea by coach) Rich Back-Card Schema: Answer + Verified verbatim excerpt + Deep link / path / author metadata
- (idea by coach) Multi-target Exporter: Native .apkg generation (with AnkiConnect push option), Markdown study sheets, and PDF flashcard grids
- (decision by user) Automated DB commit: Generated cards automatically commit to database upon generation
- (decision by user) Anki export targets: .apkg package generator, standard CSV/TSV, and direct AnkiConnect HTTP API integration
- (decision by user) Markdown export: Interactive collapsible <details><summary>Question</summary>Answer & Quote</details> blocks
- (decision by user) PDF export: Clean Q&A study guide format with answer/citation callouts
- (idea by coach) Intuitive CLI Subcommands: source (add/list/remove), sync/ingest, export (--format apkg|csv|ankiconnect|md|pdf), and cards (search/list/stats)
- (idea by coach) Filtered Export: Ability to export subsets of cards filtered by source, tag, difficulty level, or creation date range
- (idea by coach) Card Deduplication / Semantic Similarity Filter: Detects overlapping questions from multiple sources to keep decks concise
