## 1. Epic Summary

Epic 16 permanently resolved the architectural problem of brittle string-based regex parsing, markdown code-fence stripping, and quote-repair loops during LLM flashcard generation. By migrating to provider-native constrained decoding (Google Gemini responseSchema, OpenAI strict json_schema, Anthropic forced tools, and Ollama format), card generation now guarantees 100% schema compliance on the first pass at the LLM engine level.

Additionally, the epic enriched the domain schema with atomic keywords and exact sourceLocator coordinates, integrated progressive SSE card streaming with token-cutoff preservation into Task Center, deprecated over 600 lines of legacy regex sanitizers, and completed the user-facing loop across Question Explorer, Card Editor Drawer, and Anki export adapters.

## 2. Key Architectural Invariants & Achievements

1. **Invariant AD-20 (Zero-Parser Native Constrained Decoding):**
   Eliminated markdown code-fence matchers, unbalanced quote state machines, and retry loops. Responses are constrained by the inference engine itself:
   - **Gemini:** responseSchema with SchemaType object/array trees and responseMimeType: "application/json".
   - **OpenAI:** response_format: { type: "json_schema", json_schema: { strict: true, ... } }.
   - **Anthropic:** Forced tool calling via tools: [...] and tool_choice: { type: "tool", name: "emit_flashcards" }.
   - **Ollama:** Schema-constrained decoding using format: compileOllamaSchema(schema).
2. **Single Source of Truth (DialectCompiler):**
   All provider schemas derive from CardGenerationDraftSchema in packages/core/src/domain/models.ts. dialect-compiler.ts converts the Zod AST into each provider's native format, ensuring uniform field definitions, types, and descriptions (.describe()) without prompt duplication.
3. **Domain Schema & Database Backward Compatibility:**
   - Flashcards now support keywords: string[] and sourceLocator: string.
   - SQLite migration 003 safely adds keywords TEXT DEFAULT '[]' and source_locator TEXT DEFAULT '' without locking existing collections or requiring manual database migrations.
4. **Progressive Card-by-Card SSE Streaming:**
   Generation jobs stream validated cards over SSE (card_streamed event) as each chunk finishes, allowing users to watch cards appear in the Task Center accordion in real time instead of waiting for entire jobs to finish.
5. **Fault-Tolerant Partial Output Retention:**
   When LLMs hit output token limits, partial card batches are parsed with a fallback extractor and saved into SQLite. The job finishes with a completed_with_warnings status and amber notification badge, retaining all generated cards rather than failing the entire job.
6. **Full-Loop Web & Export Ecosystem Integration:**
   - **Question Explorer:** Displays keyword pills and sourceLocator badges, with instant search filtering across questions, answers, tags, keywords, and source locators.
   - **Card Editor Drawer:** Enables editing and saving keywords and source coordinates directly into SQLite.
   - **Anki Exporter & AnkiConnect:** Normalizes multi-word keywords into hyphenated Anki tags (e.g. write-ahead-logging), merges them additively with existing tags, and includes keywords and source locator badges in card back templates.

## 3. Review Findings & Remediation

Multi-lens adversarial reviews across Stories 16.3 and 16.5 identified several edge cases that were addressed and tested:

- **Thought Block Filtering in Gemini:** In newer reasoning models (e.g., Gemini 2.0 Flash Thinking), raw model parts may contain internal thoughts. The adapter now explicitly skips thought parts and extracts only the structured payload part.
- **Anthropic Tool Choice Graceful Extraction:** Guarded against edge-case API responses where Anthropic returned text before tool calls or multiple tool calls, extracting strictly from content.find(c => c.type === 'tool_use' && c.name === 'emit_flashcards').
- **Anki Whitespace Tag Normalization:** Anki disallows spaces in tags. Exporters now map keywords through regex hyphenation and deduplicate with card tags before generating .apkg or syncing via AnkiConnect.
- **Legacy Test Suite Modernization:** Updated 36 adapter tests and core repository tests to provide modern structured mock inputs, eliminating outdated expectations tied to deprecated string cleaners.
- **Cloud Provider Generation Timeout Expansion:** Increased default client-side timeout for Gemini, OpenAI, and Anthropic adapters from 30s/60s to 120s (2 minutes), and enabled configurable `timeoutMs` forwarding in worker task payloads to prevent premature aborts on multi-card structured extractions from dense documents.
