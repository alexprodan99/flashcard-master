## 2. Key Architectural Invariants & Achievements

1. **Invariant AD-19 (Zero SQLite Lock Contention):**
   Worker threads (`node:worker_threads`) never connect directly to the SQLite database. All database writes are delegated to the main-thread custodian (`WorkerExecutor`) via IPC `COMMIT_CARDS` and `COMMIT_SYNC_RESULT` messages. The main thread performs deduplication, foreign key checks, and atomic batch insertions while SQLite operates in WAL mode.
2. **Universal State Persistence (Zero DOM Keep-Alive):**
   Eliminated component state loss during navigation without relying on brittle DOM keep-alive hacks. All tab selections, search queries, multi-document checkboxes, generation parameter overrides, and drawer states are preserved in Svelte 5 runes stores (`.svelte.ts`) with `localStorage` preference retention.
3. **Bounded Multi-Processing Worker Pools:**
   Dedicated, bounded pools isolate workloads:
   - `generation`: max 2 workers (CPU/LLM bounded)
   - `sync`: max 2 workers (I/O & network bounded)
   - `export`: max 1 worker (File assembly bounded)
   Queued jobs execute in strict FIFO order, and completed/aborted workers automatically promote queued tasks.
4. **Real-time SSE Event Stream & Task Center:**
   Implemented `/api/jobs/stream` and `/api/jobs/:id/logs/stream` delivering initial snapshot events, real-time lifecycle status updates (`job_created`, `job_started`, `job_progress`, `job_completed`, `job_cancelled`), and granular step log messages rendered in `StepAccordion.svelte` inside the slide-over `TaskCenterDrawer.svelte`.
5. **Resilient UX & Action Hardening:**
   - Deep linking via browser history (`?tab=...`, `?docId=...`, `?sourceId=...`).
   - Browser Back/Forward navigation retention.
   - Global keyboard shortcuts (`1`–`5` for views, `T` for Task Center) safely guarded against typing inputs and modifier keys (`Ctrl`, `Alt`, `Meta`).
   - Disabled states with spinners during in-flight operations.
   - Non-blocking notifications via global `toastStore`.

## 3. Review Findings & Remediation

A comprehensive adversarial multi-lens review was conducted across 4 specialized review agents (Blind Hunter, Edge Case Hunter, Verification Gap, Acceptance Auditor). All 14 identified findings were triaged and resolved prior to acceptance:

- **UI Property Alignment:** Corrected field bindings in `StepAccordion.svelte` (`stepTitle`, `errorMessage`, `resultSummary`, `details`) and `taskStore.svelte.ts` SSE listener (`data.jobId || data.id`).
- **Worker IPC Metadata Retention:** Forwarded `persona` and document `tags` across `COMMIT_CARDS` in `task-worker.ts` and preserved them in `WorkerExecutor`.
- **Fault-Tolerant Worker Lifecycle:** Wrapped custodial source sync in `try/catch` with warning logs to prevent unhandled promise rejections from killing worker threads.
- **Abort Safety:** Added pre-execution abort checks in `WorkerExecutor` to immediately reject cancelled tasks with `AbortError`.
- **Orphaned Job Recovery:** Updated `JobManager.cancelJob` to mark stale/orphaned database jobs as `cancelled` even if absent from in-memory pool references.
- **SQL Empty Filter Safety:** Added `1 = 0` SQL condition in `JobRepository.list` when `filter.status` is empty array.
- **TypeScript & Schema Defaults:** Updated `CreateFlashcardInput` and `CreateSourceInput` to `z.input<...>`, making schema-defaulted fields optional for callers.
- **Build Hygiene:** Configured root `npm run typecheck` script to `tsc --noEmit` to prevent accidental in-tree emission of compiled `.js` files.
