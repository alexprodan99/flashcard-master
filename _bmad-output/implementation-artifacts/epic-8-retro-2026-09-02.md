## 1. Executive Summary

Epic 8 addressed core user experience and reliability enhancements identified during real-world study cycles:
1. **Local LLM Grounding Guard Quote Compliance:** Infused prompt instructions and LLM adapters with emphatic copy-paste directives preventing quote paraphrasing.
2. **Adaptive Generation Backfilling:** Implemented oversampling (`targetCount + 2`) and backfill retries ensuring exact user-requested card counts per chunk are fulfilled even when ungrounded drafts are rejected.
3. **Material Provenance References:** Captured and surfaced source document titles and clickable origin links on flashcards, in the editor drawer, and across exports.
4. **Printable PDF Export Support:** Fixed format routing so `/api/export?format=pdf` serves print-styled HTML study guides with `@media print` formatting.
5. **Question Explorer Multi-Selection & Bulk Deletion:** Added multi-card checkboxes, master toggle, selected item counter, and transactional bulk deletion API (`POST /api/cards/bulk`).
