## 1. Executive Summary

Epic 13 expanded the Flashcard Master publishing and generation ecosystem, delivering standardized e-reader eBook distribution, multi-tier difficulty generation, and high-productivity UX workflows:

1. **EPUB 3.0 eBook Publishing (Stories 13.1–13.2):** Implemented an uncompressed-mimetype, dual-navigation (EPUB 3 `nav.xhtml` + EPUB 2 `toc.ncx`) eBook export engine packaging knowledge base articles with localized images into `.epub` files compatible with Kindle, Apple Books, Kobo, and Calibre.
2. **Adaptive 'Mixed' Difficulty Tier (Story 13.3):** Extended domain schemas, database constraints, CLI flags, and LLM prompt adapters with a `mixed` difficulty tier that produces an adaptive progression from beginner definitions to expert application questions across documents.
3. **Question Explorer Instant Refresh (Story 13.4):** Equipped the flashcard explorer with a 1-click real-time refresh action with animated indicators that reload cards without losing active deck selections, tag filters, or search queries.
4. **Interactive File Picker & Upload (Story 13.5):** Replaced error-prone manual filesystem path typing with an interactive drag-and-drop file upload dropzone backed by `POST /api/sources/upload`, while preserving manual path entry as an advanced toggle.
5. **Monorepo Build & Verification (Story 13.6):** Validated cross-workspace TypeScript builds, cross-platform path handling (Windows/POSIX), and monorepo regression test suites.

## 3. Key Architectural Innovations & Invariants

- **AD-14 (EPUB 3.0 Standards Compliance):**
  - Uses `JSZip` to ensure the uncompressed `mimetype` file (`application/epub+zip`) is stored as the absolute first entry in the archive without compression (`compression: "STORE"`), per the IDPF EPUB 3.0 specification.
  - Generates dual navigation artifacts: `OEBPS/nav.xhtml` (modern EPUB 3 navigation document with `<nav epub:type="toc">`) and `OEBPS/toc.ncx` (legacy NCX table of contents for backward compatibility with older Kindle and e-ink devices).
- **Embedded Localized Media Packaging:**
  - Integrates directly with `MediaService` (`data/media/`), packing document image assets into `OEBPS/images/` with normalized MIME types and rewriting image tags to relative internal URIs (`images/<hash>.<ext>`).
- **AD-15 (Adaptive Mixed Difficulty Prompting):**
  - Instructs LLMs to balance synthesized flashcards across beginner fundamentals (40%), intermediate conceptual relations (40%), and expert edge-case/application scenarios (20%), providing complete coverage across technical texts.
- **AD-16 & AD-17 (Streamlined UX Workflows):**
  - Drag-and-drop file ingestion uploads documents to the server data directory, auto-generates readable titles, and validates file existence before source registration.
