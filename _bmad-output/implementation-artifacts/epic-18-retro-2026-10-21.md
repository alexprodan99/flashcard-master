## 1. Epic Summary

Epic 18 transitioned Flashcard Master into a truly knowledge-first learning environment by decoupling target flashcard decks from data sources, establishing a centralized UI Settings Studio with SQLite persistence and runtime propagation, introducing pure-JavaScript EPUB eBook ingestion with chapter slicing and media localization, and publishing curated flashcard decks as interactive EPUB 3.0 study guides.

Key milestones achieved:
- **Knowledge-First Architecture:** Completely removed `target_deck` from data source schemas, repositories, CLI commands, and UI modals. Data sources now represent immutable knowledge repositories from which users can generate multiple target decks over time. Deck selection is centralized in Generate Studio with interactive autocomplete and memory retention.
- **Centralized System Settings & Integrations Studio:** Established a dedicated Settings Studio (`SettingsView.svelte`) backed by SQLite `app_settings` and a strict 3-tier precedence hierarchy (`SQLite app_settings -> process.env fallback -> Hardcoded Default`). Settings include AI provider API keys, model defaults, generation parameters, worker pool concurrency limits, and AnkiConnect host configuration with live health testing. Sensitive keys are masked (`••••••••`), and modifications propagate dynamically to background workers without server restarts.
- **Pure-JS Local EPUB Ingestion Strategy:** Developed `EpubParser` using pure-JavaScript dependencies (`jszip`, `fast-xml-parser`, `jsdom`), zero native C++ binaries, or external tools (Calibre/Pandoc). Ingests EPUB 2 and EPUB 3 books, parses spine items and NCX/Nav tables of contents, automatically slices chapters into subdocuments, and localizes embedded image assets into `MediaService`.
- **Interactive Flashcard Deck EPUB Study Guide Exporter:** Implemented `EpubFlashcardExporter` generating standards-compliant EPUB 3.0 reflowable eBooks with uncompressed byte-0 STORE `mimetype`, XML OPF package metadata, navigation documents, deck chapters, and interactive `<details>/<summary>` answer reveal toggles styled for modern e-readers.
- **Full Monorepo Integration & Verification:** Verified all changes across all 4 monorepo packages (`@flashcard-master/core`, `@flashcard-master/adapters`, `@flashcard-master/web`, `@flashcard-master/cli`) with comprehensive test suites, full type checking, and production builds.

Ingestion parsing and EPUB packaging are isolated in `@flashcard-master/adapters`. Web routes, SSE endpoints, and UI components in `@flashcard-master/web` consume core services through dependency injection.

### Aggregate View: Pattern Divergence & Secret Masking
- **Source:** [settings-service.ts](file:///c:/Users/aprodan/Workspace/Projects/flashcard-master/packages/core/src/services/settings-service.ts#L182-L215), [server.ts](file:///c:/Users/aprodan/Workspace/Projects/flashcard-master/packages/web/src/server.ts#L2733-L2780)
- **Observation:** When loading settings in the UI, sensitive secrets are masked with bullets. During a save operation, submitting unchanged masked strings must not overwrite existing secrets. This guard was verified and strengthened during multi-lens code review.
- **Disposition:** Fixed in commit `a7377bb`.

### Review Lens: Multi-Lens Code Review Resolutions (Commit `a7377bb`)
- **Finding 1 (Masked Secret Preservation):**
  - **Source:** `packages/core/src/services/settings-service.ts:182-215`
  - **Detail:** When saving settings from the UI, masked string values (`••••••••`) are ignored so that valid stored credentials are not inadvertently overwritten with mask characters.
  - **Disposition:** Fixed in commit `a7377bb`.
- **Finding 2 (EPUB Summary XHTML5 Phrasing Compliance):**
  - **Source:** `packages/adapters/src/export/epub-flashcard-exporter.ts:250-280`
  - **Detail:** In EPUB 3 XHTML5 documents, the `<summary>` element inside `<details>` requires phrasing/inline content. Block elements inside summary were replaced with inline containers to ensure strict EPUBCheck validation compliance.
  - **Disposition:** Fixed in commit `a7377bb`.
- **Finding 3 (SVG `<image>` Remote Localization):**
  - **Source:** `packages/adapters/src/export/epub-flashcard-exporter.ts`, `packages/adapters/src/ingestion/epub-parser.ts`
  - **Detail:** Media localization was expanded to detect and cache both standard HTML `<img>` elements and SVG `<image xlink:href="...">` tags.
  - **Disposition:** Fixed in commit `a7377bb`.
- **Finding 4 (Worker Concurrency Drain Loop):**
  - **Source:** `packages/web/src/server.ts`
  - **Detail:** Dynamic updates to worker pool concurrency limits previously risked tight polling loops if set to 0. A deferred drain callback mechanism now handles pool capacity transitions gracefully.
  - **Disposition:** Fixed in commit `a7377bb`.
- **Finding 5 (Deterministic UUID Generation):**
  - **Source:** `packages/adapters/src/export/epub-flashcard-exporter.ts:110-125`
  - **Detail:** When generating EPUB package identifiers for decks without an explicit UUID, deterministic UUIDs are generated based on deck name rather than random or static fallbacks.
  - **Disposition:** Fixed in commit `a7377bb`.
