## 1. Epic Summary

Epic 3 implemented the comprehensive export and synchronization subsystem of Flashcard Master, supporting binary Anki packages, live AnkiConnect HTTP integration, RFC 4180 CSV/TSV spreadsheets, interactive Markdown active-recall guides, print-ready HTML study sheets, and a unified scoped export query engine.

### Stories Implemented (6/6 Done)
1. **Story 3.1:** Native Anki Package (.apkg) Exporter (`AnkiPackageExporter` with in-memory SQLite schema and ZIP bundling via `jszip` in `packages/adapters/src/export/anki-package-exporter.ts`)
2. **Story 3.2:** Desktop AnkiConnect Live Sync Client (`AnkiConnectAdapter` with health checks, timeout management, deck creation, and batch note synchronization in `packages/adapters/src/export/ankiconnect-adapter.ts`)
3. **Story 3.3:** Delimited CSV & TSV Exporter (`DelimitedExporter`, `CsvExporter`, `TsvExporter` with RFC 4180 quotation and delimiter escaping in `packages/adapters/src/export/delimited-exporter.ts`)
4. **Story 3.4:** Active Recall Collapsible Markdown Exporter (`MarkdownExporter` with YAML frontmatter, interactive `<details><summary>` blocks, and citation callouts in `packages/adapters/src/export/markdown-exporter.ts`)
5. **Story 3.5:** Two-Column Printable Study Guide & PDF Exporter (`HtmlStudyGuideExporter` with two-column fold-over layout, dashed fold guides, and `@media print` CSS in `packages/adapters/src/export/html-study-guide-exporter.ts`)
6. **Story 3.6:** Scoped Query & Filtered Export Engine (`ExporterRegistry` and `ExportService` supporting format negotiation, multi-attribute card queries, and batch deck exports in `packages/core/src/services/`)

   - Zero third-party telemetry. AnkiConnect communication strictly binds to `127.0.0.1:8765`, and HTML/Markdown exports are 100% self-contained with zero external CDN dependencies.

## 4. Key Learnings & Wins

- **In-Memory Anki SQLite Construction:** Packaging a complete Anki 2.1 compatible `collection.anki2` SQLite schema in a temporary directory and wrapping it with `jszip` provided instant, reliable `.apkg` generation without external Python tooling.
- **Topological Monorepo Build Ordering:** Updating the root `package.json` build pipeline to enforce `@flashcard-master/core` compilation before dependent adapter packages resolved cross-package type resolution during clean CI builds.
- **Repository Cleanup & .gitignore Audit:** Adding a comprehensive `.gitignore` and untracking compiled `dist/` artifacts ensures developers only collaborate on source TypeScript files.
