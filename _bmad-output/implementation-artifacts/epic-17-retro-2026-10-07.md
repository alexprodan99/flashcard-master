## 1. Epic Summary

Epic 17 delivered comprehensive support for rich document formats (PDF and Word `.docx`), configurable dual-mode document slicing, remote media localization for offline-ready EPUB publishing, isolated asynchronous worker ingestion, and complete state persistence across browser reloads.

Key milestones achieved:
- **Zero Native C++ Binaries:** Integrated pure-JavaScript document parsers (`unpdf` for PDF, `mammoth` for DOCX) converting text and complex tables to GitHub Flavored Markdown (GFM).
- **Strict Format Protection:** Proactively detects and rejects legacy binary `.doc` files via file extension and OLE file signatures (`0xD0CF11E0`), and detects image-only scanned PDFs with zero extractable text layers.
- **Configurable Dual Slicing Engine:** Enables semantic outline chunking (by Markdown headings and document structure) and page-budget windowing (e.g. 5–10 pages), computing deterministic IDs and propagating exact citation coordinates (`startPage`, `endPage`) into flashcard `sourceLocator` references.
- **Remote Media Bundling in EPUB:** Discovers external image URLs in document text, caches them via `MediaService`, bundles them into `OEBPS/images/`, and rewrites chapter XHTML to relative paths with graceful CSS fallback placeholders.
- **Decoupled Background Ingestion Worker:** Moves file extraction and slicing into isolated worker threads with 512MB heap limits and configurable timeout guards, reporting real-time progress via SSE.
- **State & Database Persistence:** Unified SQLite database path to canonical `~/.flashcard-master/data.sqlite` with WAL concurrency across core and CLI, and added SWR hydration in Generate Studio and Dashboard.
