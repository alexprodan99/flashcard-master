## 1. Epic Summary

Epic 19 delivered comprehensive deck lifecycle operations, high-performance data loading, granular export scoping, and cross-monorepo responsive hardening:

- **Question Explorer Infinite Scrolling & Keyset Cursor Pagination:** Transitioned the Question Explorer from loading all cards in-memory to backend keyset pagination (`listPaginated` using compound `(created_at, id)` indexes) and client-side infinite scrolling powered by an IntersectionObserver. Active deck, difficulty, search, and selection filters are preserved across fetched slices.
- **Deck Lifecycle Management (Clone, Split & Move):** Added atomic SQLite transaction-backed deck operations:
  - **Clone Deck:** Duplicates all flashcards within a deck with fresh UUIDs and preserved metadata.
  - **Batch Splitting:** Divides large decks into numbered sub-decks (`Part 1`, `Part 2`, etc.) based on configurable batch thresholds.
  - **Selective Card Movement:** Enables batch selection of cards in Question Explorer to move them directly into an existing or newly created deck.
- **Partial, Date-Filtered & Randomized Export Engine:** Enhanced `ExportService`, exporter implementations, and `ExportCenter.svelte` with:
  - Date preset shortcuts ("Last 24 Hours", "Last 7 Days", "Last 30 Days", "Custom Range") filtering by UTC timestamps.
  - Card count budgets and random subsampling with in-database shuffling (`ORDER BY RANDOM()`).
  - Added CLI export flags: `--after`, `--before`, `--limit`, and `--shuffle`.
- **Interactive Tag Selector for Data Sources:** Replaced the comma-separated text input in `AddSourceModal.svelte` and `EditSourceModal.svelte` with a keyboard-navigable `TagInput.svelte` pill component featuring auto-suggestions from `GET /api/sources/tags`.
- **Asynchronous Subdocument Generation via Task Center:** Unified subdocument synthesis from `SourceDocumentInspector.svelte` into the asynchronous background worker queue (`POST /api/generate` with `async: true`), providing live step progress and streaming logs in `TaskCenterDrawer.svelte`.
- **Responsive Layout & Overflow Hardening:** Hardened UI layouts against text clipping, long code blocks, and drawer overflows in `QuestionExplorer.svelte`, `CardEditorDrawer.svelte`, `DocumentPreviewModal.svelte`, and `TaskCenterDrawer.svelte`.
- **Generate Studio Target Scope & Modal Document Picker:** Replaced cumbersome nested accordion trees in `GenerateStudio.svelte` with prominent Source Scope Cards and created `SourceDocumentPickerModal.svelte` for fast, focused subdocument curation.

### Code Review Lenses

#### Edge-Case Lens
- **Finding 1 (Silent Page-1 Loop on Malformed Pagination Cursor):**
  - **Location:** `packages/core/src/storage/card-repository.ts:230-235`, `508-523`
  - **Trigger Condition:** Passing an invalid or corrupted cursor to `listPaginated` causes `decodeCursor` to return `null`, dropping the cursor filter condition and silently returning page 1.
  - **Guard Snippet:** `if (filter.cursor && !decodeCursor(filter.cursor)) { throw new Error("Invalid pagination cursor."); }`
  - **Potential Consequence:** Infinite scroll clients could repeatedly reload and append page 1 cards endlessly if a stale or corrupted cursor is stored.
  - **Disposition:** Fix now (Action Item).
- **Finding 2 (SQLite Parameter Limit in Batch Deletion and Card Moving):**
  - **Location:** `packages/core/src/storage/card-repository.ts:362-364`, `460-466`
  - **Trigger Condition:** Calling `moveCards` or `deleteMany` with a large card array exceeding SQLite's maximum variable limit (default 999 on older SQLite engines).
  - **Guard Snippet:** Chunk `validIds` in batches of 500 inside an atomic transaction: `for (let i = 0; i < ids.length; i += 500) { ... }`.
  - **Potential Consequence:** Bulk deck moves or deletions with 1,000+ cards throw an unhandled `too many SQL variables` SQLite error.
  - **Disposition:** Fix now (Action Item).
- **Finding 3 (Empty `documentIds` Array Accidental Fallback to Entire Database):**
  - **Location:** `packages/web/src/server.ts:2269-2293`
  - **Trigger Condition:** When `POST /api/generate` receives `{ documentIds: [] }`, the `length > 0` check fails, falling through to the `else` branch which fetches all active sources.
  - **Guard Snippet:** `if (Array.isArray(body.documentIds) && body.documentIds.length === 0) { this.sendJson(res, 400, { error: "No documents selected for generation." }); return; }`
  - **Potential Consequence:** Deselecting all documents in Generate Studio could inadvertently enqueue jobs across all documents in the database.
  - **Disposition:** Fix now (Action Item).
- **Finding 4 (CLI `--all-decks` Ignores Scoping Options):**
  - **Location:** `packages/cli/src/cli.ts:541-556`, `packages/core/src/services/export-service.ts:71-104`
  - **Trigger Condition:** Executing `flashcard-master export <format> --all-decks <dir>` with `--after`, `--before`, `--limit`, or `--shuffle` flags.
  - **Guard Snippet:** Forward filter options to `exportAllDecks` or emit a warning if partial scoping flags are supplied alongside `--all-decks`.
  - **Potential Consequence:** Users expecting time-scoped or budget-limited exports across all decks receive full, unfiltered deck dumps.
  - **Disposition:** Fix now (Action Item).

#### Adversarial Lens
- **Finding 5 (Deck Splitting Collisions with Existing Sub-Decks):**
  - **Location:** `packages/core/src/storage/card-repository.ts:420-447`
  - **Trigger Condition:** Running `splitDeck` when target subdecks (`${sourceDeck} - Part 1`) already exist from a previous split.
  - **Guard Snippet:** Verify if destination subdecks contain cards prior to running the split transaction, or provide a flag to replace/append explicitly.
  - **Potential Consequence:** Re-splitting a deck merges new batches into existing sub-decks, resulting in unbalanced card distribution across parts.
  - **Disposition:** Defer; low probability during typical user workflows.
- **Finding 6 (Client Selection Set Memory Scaling):**
  - **Location:** `packages/web/client/src/stores/explorerStore.svelte.ts:18-35`
  - **Trigger Condition:** Using "Select All Filtered" when browsing collections with tens of thousands of cards.
  - **Guard Snippet:** Store selection modes as an algebraic state (`{ mode: 'all_filtered', excludedIds: Set<string> }` vs `{ mode: 'explicit', ids: Set<string> }`).
  - **Potential Consequence:** High memory footprint if tens of thousands of UUIDs are held in a reactive client set.
  - **Disposition:** Defer; current collection sizes in typical self-hosted deployments are well within memory limits.

#### Verification-Gap Lens
- **Finding 7 (Missing Test for Invalid Cursor Rejection):**
  - **Location:** `packages/core/test/card-repository.test.ts`
  - **Trigger Condition:** No automated unit test verifies `listPaginated` behavior when provided with an invalid or corrupted cursor string.
  - **Guard Snippet:** Add unit test in `card-repository.test.ts` asserting error behavior on corrupted Base64 strings.
  - **Potential Consequence:** Regressions in cursor validation logic could pass continuous integration undetected.
  - **Disposition:** Fix now (Action Item).
- **Finding 8 (Missing Test for CLI `--all-decks` Filter Incompatibility):**
  - **Location:** `packages/cli/test/cli.test.ts`
  - **Trigger Condition:** CLI test suite does not exercise combinations of `--all-decks` with `--limit` or `--after`.
  - **Guard Snippet:** Add test asserting CLI warning or filter propagation during all-decks export.
  - **Potential Consequence:** Scoping regressions in CLI bulk exports remain unverified.
  - **Disposition:** Fix now (Action Item).
