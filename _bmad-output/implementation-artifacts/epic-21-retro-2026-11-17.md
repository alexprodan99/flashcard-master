## 2. Findings (Aggregate Views & `bmad-review` Code Lenses)

### A. Product & Architecture Design Findings

1. **Media slicing strategy is sync-time only and lacks source-level persistence + per-item overrides**
   - **Source:** `packages/core/src/domain/models.ts` (`MediaSourceItemSchema`), `packages/web/client/src/components/EditSourceModal.svelte`, `packages/web/client/src/components/MediaItemListEditor.svelte`, `packages/core/src/services/ingestion-service.ts:113-177`
   - **Observation:** `extractionMode`, `sttProvider`, `subtitlePath`, and `timestampRanges` are persisted per `MediaSourceItem` and editable in `EditSourceModal`, whereas `slicingMode` (`chapters` | `timestamps` | `none`) and `intervalMinutes` are only supplied transiently at Sync time for the whole source. Mixed-content sources (e.g., a chaptered lecture alongside an unchaptered interview or short clip) cannot customize slicing per video, and editing a source does not expose slicing defaults.
   - **Disposition:** **Fix now (Action Item 1)** — Add optional source-level slicing defaults and optional per-item slicing overrides (`inherit` | `chapters` | `timestamps` | `none`) editable on demand, with Save & Re-sync / dirty-slicing detection.
   - **Upstream Lesson:** Treat ingestion transformation parameters (like slicing) alongside extraction parameters in the initial domain schema (`21.1`) rather than as sync-only UI modal state.

2. **Desktop `asarUnpack` rule broke `electron-builder` on monorepo workspace paths**
   - **Source:** `packages/desktop/electron-builder.json` (fixed in `3a01802`, PR `#90`), `node_modules/app-builder-lib/out/util/filter.js:24-33`
   - **Observation:** Adding `asarUnpack` for `ffmpeg-static` / `ffprobe-static` in Story `21.3` caused `app-builder-lib` to validate every asar-included file against `packages/desktop/`, failing all 3 OS builds on `../../packages/adapters/dist/...` until removed in PR `#90` (`smartUnpack` already unpacks native binaries automatically).
   - **Disposition:** **Accept as-is** (resolved in `3a01802`).
   - **Upstream Lesson:** Run `npm run desktop:dir` locally whenever `packages/desktop/electron-builder.json` is modified.

3. **God-class / file-size growth across top-churn modules**
   - **Source:** `packages/web/src/server.ts` (3,704 lines), `packages/adapters/src/ingestion/youtube-strategy.ts` (1,380 lines), `packages/core/src/services/document-slicing-engine.ts` (1,003 lines), `packages/adapters/src/stt/local-whisper-stt-adapter.ts` (942 lines)
   - **Observation:** `server.ts` continues to absorb new route groups (`/api/settings/media/diagnostics`, `/api/sources/upload`) and `youtube-strategy.ts` bundles URL parsing, caption XML/VTT decoding, chapter extraction, `yt-dlp` binary management, and STT orchestration in one file.
   - **Disposition:** **Defer** — Extract route modules from `server.ts` and split `yt-dlp` binary management / caption parsing out of `youtube-strategy.ts` in future refactoring.

### B. Adversarial Lens (`bmad-review`)

4. **Path traversal via unsanitized `input.filename` in `LocalWhisperSttAdapter.transcribeViaCli`**
   - **Source:** `packages/adapters/src/stt/local-whisper-stt-adapter.ts:775-778`
   - **Observation:** `const safeName = input.filename?.trim() || "audio.wav"; audioFilePath = path.join(workDir, safeName); await fs.writeFile(audioFilePath, input.audioBuffer);` does not strip directory segments via `path.basename()`.
   - **Disposition:** **Fix now (Action Item 2)** — Sanitize with `path.basename` and validate resolved path remains inside `workDir`.

5. **Backslash zip-slip traversal in `extractWhisperArchive`**
   - **Source:** `packages/adapters/src/stt/local-whisper-stt-adapter.ts:177-189`
   - **Observation:** `path.posix.basename(entryName)` only splits on `/`, not `\`. On Windows, an entry like `..\..\evil.dll` retains `..\` segments and writes outside `binDir` via `path.join(binDir, destName)`.
   - **Disposition:** **Fix now (Action Item 2)** — Normalize backslashes before taking `basename` and enforce `resolvedDest.startsWith(resolvedBinDir + path.sep)`.

6. **Silent error swallowing for failed background media syncs in `WorkerExecutor`**
   - **Source:** `packages/web/src/workers/worker-executor.ts:322-348`, `packages/core/src/services/ingestion-service.ts:283-295`, `packages/web/src/workers/task-worker.ts:592-600`
   - **Observation:** `IngestionService.syncSource` catches exceptions and returns `{ error: err.message, newCount: 0, totalFetched: 0 }`, while `WorkerExecutor` only reads `newCount` and `totalFetched` without inspecting `syncResult.error`. Failed media syncs (missing subtitles, unavailable YouTube video, STT auth errors) are reported as `"completed"` with 0 documents.
   - **Disposition:** **Fix now (Action Item 3)** — Propagate/log `syncResult.error` in `WorkerExecutor` so failed sync jobs surface as `failed` or `completed_with_warnings` in the Task Center.

7. **Unbounded memory buffering in `WebServer.readRequestBodyBuffer`**
   - **Source:** `packages/web/src/server.ts:1711-1720, 2631, 2665`
   - **Observation:** `readRequestBodyBuffer(req)` buffers all incoming chunks via `Buffer.concat(chunks)` with no maximum byte limit.
   - **Disposition:** **Defer (Action Item 6)** — Add a configurable max upload byte limit (returning HTTP `413 Payload Too Large`).

8. **Uncaught `RangeError` in `decodeHtmlEntitiesOnce` on out-of-range numeric entities**
   - **Source:** `packages/adapters/src/ingestion/youtube-strategy.ts:189-190`
   - **Observation:** `String.fromCodePoint(Number(code))` and `String.fromCodePoint(parseInt(hex, 16))` throw `RangeError` if a caption/metadata entity exceeds `0x10FFFF`.
   - **Disposition:** **Defer (Action Item 6)** — Guard code point range (`0 <= cp <= 0x10FFFF`) before calling `String.fromCodePoint`.

### C. Edge-Case Lens (`bmad-review`)

9. **Re-sync transitions and redundant paid STT calls in `IngestionService.syncSource`**
   - **Source:** `packages/core/src/services/ingestion-service.ts:83, 106-120, 173-258`, `packages/adapters/src/ingestion/youtube-strategy.ts:1350`, `packages/adapters/src/ingestion/media-transcript-resolver.ts:460-478`
   - **Observation:**
     - Re-syncing a previously sliced source with `slicing.mode = "none"` skips `deleteBySourceId(source.id)` (leaving orphaned sliced subdocuments) and skips emitting the full document when `contentHash` matches.
     - `strategy.fetch()` runs before `contentHash` deduplication and does not short-circuit unchanged media items before invoking paid STT.
     - When `isSlicingActive === false`, Loop 2 (`docsToPersist`) re-upserts all `rawDocs` even when Loop 1 skipped them as unchanged.
     - Empty `sliceByCustomTimestampRanges` results (`[]`) trigger `deleteBySourceId(source.id)` followed by `upsertBatch([])`, wiping existing documents.
   - **Disposition:** **Fix now (Action Item 4)** — Handle `sliced -> none` cleanup, avoid wiping docs on empty custom-range matches without warning, and prevent redundant STT/upsert work on unchanged items.

10. **Client/server validation drift & stale modal state**
    - **Source:** `packages/web/client/src/components/MediaItemListEditor.svelte:27, 101-103`, `packages/web/client/src/lib/formatters.ts:148, 162-168`, `packages/web/client/src/components/AddSourceModal.svelte:53-72, 233-239`, `packages/core/src/services/subtitle-parser.ts:60-76`, `packages/cli/src/cli.ts:23-36, 230-240`
    - **Observation:**
      - `TIMESTAMP_REGEX` accepts `00:99` and skips `end > start`; `SubtitleParser.parseTimestampToSeconds` accepts `":30"` (`Number("") === 0`); `AddSourceModal` keeps stale `mediaItems` when switching between `youtube`/`audio`/`video`; `handleAddYoutubeUrls` rejects `m.youtube.com` / `music.youtube.com` / `youtube-nocookie.com`; CLI `parseCliTimestampRanges` does not validate range syntax/order and `sources add` ignores `--stt-provider`/`--subtitles` when `uri` is JSON.
    - **Disposition:** **Fix now (Action Item 5)** — Align timestamp, YouTube URL, and modal type-switch validation across client, CLI, and core `SubtitleParser`.

11. **`LocalWhisperSttAdapter` binary classification & `AudioTrimmer` fallback chunking**
    - **Source:** `packages/adapters/src/stt/local-whisper-stt-adapter.ts:785-788`, `packages/adapters/src/media/audio-trimmer.ts:524, 685-699`
    - **Observation:** Custom `main` / `main.exe` `whisper.cpp` binaries are misclassified as Python `whisper` CLI; `AudioTrimmer` byte-based fallback duration can overestimate length when `probeDurationSeconds` returns `null`, and `runFfmpeg` has no default timeout.
    - **Disposition:** **Defer (Action Item 6)**.

### D. Verification-Gap Lens (`bmad-review`)

12. **Component UI tests, `WorkerExecutor` error propagation, and real `ffmpeg-static` integration coverage**
    - **Source:** `packages/web/test/media-source-ui.test.ts:289-381`, `packages/adapters/test/media-e2e.test.ts`, `packages/cli/test/cli.test.ts:574-652`

    - **Disposition:** **Fix now (Action Item 7)** — Add tests alongside Action Items 1–5.
